# Aryan Singhal — Technical Operator & Founder's Office Portfolio

A personal proof-of-work portfolio focused on high-leverage operations, deterministic systems architecture, and unit economics for Series A and Series B startups.

## Stack
- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui primitives
- **Icons**: Lucide React
- **Design Philosophy**: Unslop — quiet chrome, editorial typography, high information density, and interactive systems.

## Local Development
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```
